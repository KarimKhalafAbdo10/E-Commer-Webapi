🛒 E-Commerce Web API
A robust backend service for managing an e-commerce platform. This API provides endpoints for handling products, categories, users, authentication, and orders. Built with ASP.NET Core Web API and integrated with SQL Server for data persistence.
🚀 Features
👤 User Authentication & Authorization

Register, login, and manage accounts

Secure password hashing & JWT authentication

📦 Product & Category Management

CRUD operations for products and categories

Filtering and grouping by category

🛍️ Order & Cart Handling

Add/remove items from cart

Place and track orders

⚙️ Admin Controls
Manage users, roles, and system settings

📖 API Documentation

Swagger UI available for testing and exploring endpoints
🛠️ Tech Stack
Backend: ASP.NET Core Web API

Database: Microsoft SQL Server (MSSQL)

Authentication: JWT Tokens

Deployment: Hosted on MonsterASP.NET

Documentation: Swagger UI
⚡ Getting Started
Prerequisites
.NET SDK (latest version)

SQL Server (local or hosted)

Installation
1-Clone the repository:
git clone https://github.com/KarimKhalafAbdo10/E-Commer-Webapi.git
2-Navigate to the project folder:cd E-Commer-Webapi
3-Update appsettings.json with your SQL Server connection string.
4-Apply migrations:dotnet ef database update
5-Run the API:dotnet run
